### Tujuan

## 📝 Dokumentasi Kegiatan Workshop (Day 1)

### 1. Rangkuman Materi
* **Pengenalan Dasar Sistem & Git/GitHub:** Mempelajari konsep dasar version control system (VCS), inisialisasi repository lokal, hingga cara melakukan *commit* dan *push* proyek ke platform GitHub secara publik.
* **Pengelolaan Struktur Dokumentasi:** Memahami pentingnya membuat file dokumentasi yang bersih dan mudah dibaca menggunakan format **Markdown** (`.md`).
* **Praktik Terbaik (Best Practices):** Panduan dalam menyusun tata letak folder dan penamaan file agar proyek atau tugas terorganisir dengan baik dan profesional.

### 2. Poin-Poin Penting & Pengetahuan Baru
* Mengetahui cara kerja perintah dasar Git (seperti `git init`, `git add`, `git commit`, dan `git push`) untuk menghubungkan direktori lokal dengan repository jarak jauh di GitHub.
* Memahami fungsi file `README.md` sebagai gerbang utama dokumentasi proyek yang harus memuat identitas, tujuan, serta isi materi secara transparan.
* Menyadari pentingnya menjaga visibilitas repository tetap **Public** agar portofolio dan hasil pengerjaan tugas dapat diakses serta diverifikasi dengan mudah.

### 3. Refleksi & Pendapat Pribadi
* **Kesan:** Kegiatan Day 1 ini sangat aplikatif dan membantu menjembatani pemahaman teori pengelolaan proyek dengan praktik langsung menggunakan platform industri seperti GitHub.
* **Tantangan:** Perlu ketelitian ekstra dalam mengikuti instruksi penamaan repository dan struktur folder agar sesuai persis dengan ketentuan panitia.
* **Manfaat:** Menambah wawasan baru mengenai pentingnya kebiasaan mendokumentasikan setiap proses belajar secara rapi, yang nantinya sangat berguna untuk rekam jejak akademik maupun profesional ke depan.
